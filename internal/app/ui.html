Nowy token

    
Token działa jak hasło: wysyłasz go w nagłówku Authorization: Bearer …
      (np. curl -H "Authorization: Bearer asi_…" /api/v1/assets). W bazie trzymamy tylko hash SHA-256,
      więc wartość pokazujemy raz, przy tworzeniu.
